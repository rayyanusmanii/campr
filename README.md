# Campr

**Campr** is a social camping web app designed to help users plan, book, and share camping experiences. 
It features a functional prototype with a demo login page and location-based planning tools.  

![Screenshot](/camprss.png)  
Feel free to check out the project [here](https://devpost.com/software/campr-j67ues)


---

## Features

- **User Authentication:** Login page with local user authentication for hackathon demo.  
- **Camping Planner:** Plan and book camping trips with interactive location-based features.
